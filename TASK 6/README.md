# Password Security Evaluation

## Overview
This task explores password strength by creating multiple passwords with varying complexity, testing them on a password strength checker and document in feedback. The goal is to identify best practices for creating strong passwords and understand how complexity impacts security.

## Best Practices Learned
- Use **at least 15 characters**.
- Include **uppercase, lowercase, numbers, and symbols**.
- Avoid repeated patterns oe predictable words.
- Longer, random combinations significantly increase cracking time

---
## Common Password Attacks
- **Brute Force Attack**: Tries every possiblr combination until the correct password is found. Short/simple passwords are easily cracked.
- **Dictionary Attack**: Uses precompiled lists of common words, phrases, or leaked passwords. Predictable passwords are vulnerable.

---
## How Password Complexity Affects Security
Password strength depends on:  
- **Length**: Longer passwords exponentially increase difficulty.  
- **Character Variety**: Mixing letters, numbers, and symbols reduces predictability.  
- **Unpredictability**: Avoiding common words or patterns prevents dictionary attacks.  
- **Entropy**: Randomness increases resistance against automated cracking tools.  

---

## Key Security Concepts
1. **Strong Passwords**: Long, unpredictable, mixed characters.  
2. **Password Attacks**: Brute force, dictionary, credential stuffing, phishing.  
3. **Length Importance**: More characters = exponentially harder to crack.  
4. **Dictionary Attack**: Exploits common words and predictable choices.  
5. **Multi-Factor Authentication (MFA)**: Adds extra security layers beyond passwords.  
6. **Password Managers**: Generate and store unique, complex passwords securely.  
7. **Passphrases**: Long, memorable phrases that are harder to crack.  
8. **Common Mistakes**: Short passwords, reuse across accounts, personal info, predictable patterns.  

---

## Conclusion
Password complexity is critical for security. Strong passwords combined with MFA and password managers provide the best defense against brute force and dictionary attacks. Avoiding common mistakes ensures resilience against modern threats.
